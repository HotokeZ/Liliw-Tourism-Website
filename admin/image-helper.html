📋 How to Save Images:

  1. Click "Download Image" on any image below
  2. Save the file to the images/ folder in your project
  3. Use the exact filename shown (don't rename it)
  4. After saving all images, you can refresh your website to see them appear
  5. Click "Clear All" once you've saved all images
